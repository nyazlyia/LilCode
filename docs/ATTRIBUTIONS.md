# Atribusi

## Aset visual
Seluruh karakter (Kiko, Pipo), tile peta, bendera, ikon, dan favicon adalah **SVG buatan sendiri** untuk proyek ini
(`resources/views/partials/sprite.blade.php`, `public/favicon.svg`). Tidak ada gambar, ilustrasi, atau suara dari sumber lain.

## Font (SIL Open Font License 1.1, lewat paket Fontsource)
- Baloo 2 - judul dan tombol
- Lexend - isi teks
